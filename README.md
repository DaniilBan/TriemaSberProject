# Деидентификация документов

Локальный мультиагентный AI-помощник для автоматического обезличивания (деидентификации) конфиденциальных данных в тендерных документах: договорах, финансовых отчётах, коммерческих предложениях.

Приложение обрабатывает документы в форматах **PDF / DOCX / XLSX**, находит конфиденциальные сущности (ИНН, ФИО, адреса, названия компаний и т.д.), заменяет их на маскировочные маркеры и сохраняет результат с визуальной подсветкой всех изменений плюс подробные отчёты о заменах.

---

## Возможности

- **Три формата документов**: DOCX, XLSX, PDF (включая OCR для сканов).
- **Извлечение сущностей через GigaChat**: ФИО, адреса, названия организаций, стороны договора.
- **Структурированные сущности регулярками**: ИНН, КПП, ОГРН, ОГРНИП, СНИЛС, телефоны, e-mail.
- **Валидатор полноты**: проверяет, все ли сущности найдены, при необходимости задаёт уточняющие вопросы.
- **Свои типы данных**: можно указать любые типы помимо стандартных через GUI.
- **Пофрагментная подсветка**:
  - DOCX — жёлтая заливка заменённых фрагментов.
  - XLSX — красный жирный шрифт для масок + светло-жёлтая заливка ячеек.
  - PDF — красные пометки в местах замены.
- **Отчёты о заменах**: JSON (машиночитаемый) + TXT (человекочитаемый).
- **История обработок** с сохранением в `history.json` и очисткой вместе с файлами.
- **Современный GUI** на `customtkinter` с тёмной темой.
- **Замена LLM без правки логики**: интерфейс `LLMInterface` позволяет переключиться с GigaChat на локальную модель.

## Требования

- **Python 3.10+** (проверено на 3.11).
- **GigaChat API key** (Authorization key из [GigaChat Studio](https://developers.sber.ru/studio/)).
- **Интернет-соединение** для обращения к GigaChat API.
- Опционально для OCR сканированных PDF: **Tesseract OCR** и **Poppler**.

## Установка

### 1. Клонировать репозиторий

```bash
git clone <url>
cd TriemaSberProject_2
```

### 2. Создать виртуальное окружение

Windows:

```cmd
python -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```cmd
python -m pip install -r requirements.txt
```

Если `requirements.txt` отсутствует, установите вручную:

```cmd
python -m pip install python-dotenv gigachat PyMuPDF python-docx openpyxl pdfplumber pydantic docx2python customtkinter pandas
```

Для работы с сканами PDF:

```cmd
python -m pip install pdf2image pytesseract
```

### 4. Настроить `.env`

Создайте файл `.env` **в корне проекта** (рядом с `main.py`):

```env
GIGACHAT_CREDENTIALS=ваш_authorization_key_из_GigaChat_Studio
```

> **Важно:** `.env` не должен попадать в git (см. `.gitignore`). Ключ берите именно **Authorization key**, а не Client ID / Client Secret.

## Использование

1. **Выберите документ** — кнопка «Обзор…» или вставьте путь вручную.
2. **Отметьте типы данных**, которые нужно маскировать:
   - ИНН, КПП, ОГРН/ОГРНИП, телефоны, e-mail, ФИО, адреса, стороны договора, паспорт.
3. **Свои типы (опционально)** — введите через запятую и нажмите «Применить». Появятся чипсы, клик по `✕` удаляет тип.
4. **Нажмите «▶ Обработать документ»**.
5. Дождитесь завершения. Прогресс виден в журнале.
6. **По завершении** откроется окно с кнопками открытия:
   - обезличенного документа,
   - JSON-отчёта,
   - TXT-отчёта.

### Где сохраняются результаты

```
output/
├── masked/      ← обезличенные документы
└── reports/     ← JSON и TXT отчёты
```

При повторной обработке файла создаётся новая версия с суффиксом `_v2`, `_v3` — старые результаты не перезаписываются.

### История обработок

Все записи сохраняются в `history.json` рядом с приложением. Клик по записи открывает окно с результатами. Кнопка **«Очистить»** удаляет и записи, и связанные файлы с диска.

## Архитектура

Пайплайн:

```
[Входной файл]
      │
      ▼
[1. Parser] ── DOCX / XLSX / PDF
      │
      ▼
[2. LLM] ── GigaChat извлекает сущности (JSON)
      │
      ▼
[3. Validator] ── проверяет полноту, задаёт вопросы пользователю
      │
      ▼
[4. Masker] ── применяет маски к документу
      │
      ▼
[Обезличенный документ + JSON/TXT отчёты]
```

### Ключевые модули

| Модуль | Роль |
|---|---|
| `interfaces.py` | Абстрактные базовые классы. Позволяют менять LLM и парсеры независимо. |
| `llm_layer.py` | Клиент GigaChat + устойчивый 4-уровневый JSON-парсер. Решает проблему «битых» ответов LLM. |
| `interactive_validator.py` | Второй проход по документу: проверяет полноту, при необходимости уточняет у пользователя. |
| `document_masker.py` | Модуль маскирования. Для DOCX — пофрагментная подсветка (жёлтая заливка). Для XLSX — rich-текст. Для PDF — redaction annotations. |
| `report_generator.py` | Формирует отчёт о заменах: подробный JSON + читаемый TXT. |
| `gui/*` | GUI на `customtkinter`, история обработок, модальные диалоги. |

## Устойчивость к сбоям

**4-уровневый JSON-парсер** в `llm_layer.py` защищает от типичных дефектов в ответах LLM:

1. Чистый JSON.
2. Починка trailing comma и управляющих символов.
3. Поиск сбалансированного объекта через сканер скобок.
4. Regex-fallback: извлечение сущностей даже из полностью битого ответа.

**Особенности маскирования:**

- DOCX: run'ы собираются рекурсивно (включая `w:hyperlink`, `w:sdt`, `w:smartTag`).
- XLSX: используется `CellRichText` + `rich_text=True` при чтении — маски находятся во всех вхождениях, формулы не затронуты.
- PDF: устойчивый поиск (точный / по пробелам / пословный), дедупликация прямоугольников.

**Фоллбэк LLM:** при ошибке инициализации GigaChat используется `LocalOllamaLLM` — заглушка, которая возвращает пустой список. **Внимание:** в этом режиме сущности не извлекаются, и в журнале появится предупреждение.

## Возможные проблемы

### `No module named 'gigachat'`

```cmd
python -m pip install gigachat
```

### `No module named 'dotenv'`

```cmd
python -m pip install python-dotenv
```

### «GIGACHAT_CREDENTIALS не задан», хотя `.env` есть

Проверьте:

```cmd
python -c "import os; from pathlib import Path; from dotenv import load_dotenv; load_dotenv(Path('main.py').resolve().parent / '.env'); print('CRED:', bool(os.getenv('GIGACHAT_CREDENTIALS')))"
```

Если `CRED: False` — файл `.env` повреждён (BOM, кавычки, пробелы вокруг `=`). Сохраните в UTF-8 без BOM.

### `[Errno 13] Permission denied` при повторной обработке

Файл открыт в Word / Excel / PDF-просмотрщике. Закройте его — приложение автоматически создаст новую версию `_v2`, `_v3` в `output/masked/`.

### «Используется фоллбэк LocalOllamaLLM»

GigaChat не подключился. В журнале выше есть строка с причиной — обычно это отсутствующие credentials или сетевые проблемы.

### OCR не работает

Установите Tesseract и Poppler:

- **Windows**: [Tesseract installer](https://github.com/UB-Mannheim/tesseract/wiki) + [Poppler](https://github.com/oschwartz10612/poppler-windows/releases)
- **Linux**: `sudo apt install tesseract-ocr tesseract-ocr-rus poppler-utils`
- **macOS**: `brew install tesseract tesseract-lang poppler`

И убедитесь, что установлены Python-обёртки:

```cmd
python -m pip install pdf2image pytesseract
```

## Ограничения

- **Recall извлечения сущностей ~70%** при использовании только LLM. Точность повышается при подключении гибридного пайплайна (регулярки + программная генерация вариантов).
- **XLSX** не позволяет задать фоновую подсветку отдельного фрагмента — маски выделяются красным жирным шрифтом, а изменённые ячейки получают светло-жёлтую заливку.
- **GigaChat** работает синхронно; обработка больших документов (100+ страниц) может занять несколько минут.
- **Сканы PDF** требуют установленного Tesseract; качество OCR зависит от разрешения.
